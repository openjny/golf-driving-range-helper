# ⛳ ゴルフ練習場ヘルパー

ゴルフ練習場でのターゲット練習をサポートするWebアプリケーションです。

ランダムに生成されるターゲット（距離・OKゾーン）を狙い、1球ごとに結果を記録することで、実戦に近い練習ができます。

## 機能

- 🎯 **ランダムターゲット生成** — 距離帯・OKゾーン（楕円）が毎回変わる
- 📏 **飛距離プロフィール** — ドライバー飛距離（150〜300yd）を選ぶと距離帯が自動スケール
- ⚙️ **シビアさ調整** — OKゾーンの広さを「ゆるめ / ふつう / シビア」で変更
- 🔄 **ショット遷移ルール** — 本番のラウンドに近いショット順序で出題（後述）
- 📊 **セッション統計** — 練習終了後にショット種別ごとの成功率を表示
- 📱 **モバイルフレンドリー** — 練習場での片手操作を想定したUI

## ターゲット種別と距離帯

6つの距離帯が定義されており、選択した飛距離プロフィールに応じて比例スケールされます。
以下はデフォルト（210yd）の場合です。

| ターゲット | 基準距離範囲 | 210ydでの距離 | 出現頻度 |
|---|---|---|---|
| ロングショット | 200-250yd | 170-210yd | 26% |
| ミドルショット（長） | 150-200yd | 130-170yd | 14% |
| ミドルショット（短） | 100-150yd | 80-130yd | 17% |
| ハーフショット | 50-100yd | 40-80yd | 10% |
| アプローチ（ピッチ） | 30-50yd | 30-40yd | 15% |
| アプローチ（チップ&ラン） | 10-30yd | 10-30yd | 18% |

## ロジック

### 距離スケーリング

各テンプレートの基準距離範囲（最大250yd基準）が、選択プロフィールの `maxDistance` で比例スケールされます。

```
実距離 = 基準距離 × (maxDistance / 250)
```

距離は10yd刻みに丸められ、最小10ydが保証されます。

### OKゾーン（楕円）

ターゲットごとに楕円形のOKゾーンが設定されます。半径は距離に対する比率で決まります。

- **縦半径** = `距離 × depthRatio`（短距離ほど大きい：6〜15%）
- **横半径** = `距離 × widthRatio`（長距離ほど大きい：7〜10%）

これは実際のTrackman計測データに基づくショット散布パターンを反映しています（ドライバーは横に散りやすく、ウェッジは縦に散りやすい）。

シビアさにより比率が ±2% オフセットされます。

### 重み付きランダム選択

各プロフィールにはテンプレートごとの出現重み（weight）が定義されており、重み付きランダム選択で次のターゲットが決まります。飛距離が大きいプロフィールほどショートゲーム（50yd以内）の割合が高くなります。

### ショット遷移ルール

本番のラウンドに近い順序でターゲットが出題されます。

- **同じショットの連続禁止** — ロングショット→ロングショット等は出現しない
- **前進のみ** — ホール内ではグリーンに近づく方向のみ許可（例：ミドルショット後にロングショットは不可）
- **新ホール復帰** — ミドルショット（短）以降からロングショットに戻れる
- **アプローチ後は自由** — 新ホール開始として任意のショットが出現可能

遷移ルールは許可されたテンプレートにフィルタしてから重み付き選択するため、許可テンプレート間の相対的な重み比率は維持されます。
