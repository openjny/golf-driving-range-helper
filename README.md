# ⛳ ゴルフ練習場ヘルパー

ゴルフ練習場でのターゲット練習をサポートするWebアプリケーションです。

ボタンを押すたびにランダムなターゲット（距離・OK幅・OB有無）が表示され、1球ごとに異なるターゲットを狙う実戦的な練習ができます。

## 機能

- 🎯 ランダムターゲット生成（名前・距離・OK縦幅・OK横幅・左右OB有無）
- 📊 実際のラウンドに近いショット配分でターゲットが出現
- 📱 モバイルフレンドリーなUI（練習場での使用を想定）
- 🔢 球数カウンター

## ターゲット種別

| ターゲット | 距離範囲 | 出現頻度 |
|---|---|---|
| ドライバー ティーショット | 200-250yd | ~18% |
| フェアウェイウッド ティーショット | 180-220yd | ~7% |
| ロングアイアン Par3 | 170-200yd | ~4% |
| ミドルアイアン Par3 | 140-170yd | ~4% |
| ショートアイアン Par3 | 100-140yd | ~4% |
| セカンドショット（ロング） | 150-200yd | ~11% |
| セカンドショット（ミドル） | 100-150yd | ~22% |
| セカンドショット（ショート） | 50-100yd | ~18% |
| サードショット（Par5） | 80-140yd | ~7% |
| レイアップショット | 100-180yd | ~5% |
